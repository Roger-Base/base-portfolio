# Base Portfolio 🟦

**Simple portfolio viewer for Base network**

Enter any Base address to instantly view:
- ETH balance
- Total USD value  
- Token holdings

## Why?

Most blockchain tools are complicated. This is simple:
1. Enter address
2. See balance
3. Done

Perfect for:
- Checking if someone paid you
- Viewing your own portfolio
- Checking any address on Base
